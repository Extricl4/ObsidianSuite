Factory presets (built into the plugin). Factory/ holds the plugin's own sounds, Artists/<artist>/
the song and album tones. They are generated: edit plugin/tools/presets/factory.py or artists.py and run
plugin/tools/presets/make_presets.py (it level-matches every preset on the real plugin).
You can also save a preset in the plugin and copy it here from Documents\Obsidian Amp Suite\Presets
(rename .obsidian to .json). File names must be unique across all folders.
