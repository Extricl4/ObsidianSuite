# Obsidian Suite

Emil's amp-sim plugin suite: amps, cabs, pedals and the Obsidian host UI.

| Folder | What | Worked on in chat |
|---|---|---|
| `visuals/` | 3D render toolkit: one spec per amp, cab and pedal, plus textures and Blender scripts | **Amps & Cabs**, **Pedals** |
| `ui/` | The Obsidian interactive demo (header, tabs, tuner, settings, EQ, synth) | **Program** |
| `plugin/` | The future JUCE VST3: NAM loading, IRs, DSP | **Program** |

## How the chats share work
Every chat in the Obsidian Suite project clones this repo, works only in its own folder, and commits back.
The Program chat puts the finished plugin together from all of it.
